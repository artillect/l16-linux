A release candidate for 0.1.0, built to test the release image and a Linux-only install. Not for general use: wait for 0.1.0.

> [!WARNING]
> In-development port: flashing it can leave your camera unable to boot, and it runs lightly tested drivers. [Back up your stock partitions](https://github.com/artillect/l16-linux/wiki/Unlocking-and-backups) first. No warranty.

| File | What |
|---|---|
| `light-lfc-rootfs.img.xz` | Root filesystem (sparse image; decompress first) |
| `light-lfc-boot.img` | Signed kernel image |
| `SHA256SUMS` | Checksums |
