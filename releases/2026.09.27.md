First prebuilt image: postmarketOS v26.06 with Phosh for the Light L16, dual-booted with the stock LightOS.

> [!WARNING]
> In-development port: flashing it can leave your camera unable to boot, and it runs lightly tested drivers. [Back up your stock partitions](https://github.com/artillect/l16-linux/wiki/Unlocking-and-backups) first. No warranty.

**Install:** see [Installation](https://github.com/artillect/l16-linux/wiki/Installation). You need an unlocked bootloader and a `linux` partition.

**Log in** as `user` with password `147147`, and change it right away. SSH is off; turn it on with `sudo rc-update add sshd default` after changing the password if you want it.

| File | What |
|---|---|
| `light-lfc-rootfs.img.xz` | Root filesystem for the `linux` partition (sparse image; decompress first) |
| `light-lfc-boot.img` | Signed kernel image for `recovery` |
| `SHA256SUMS` | Checksums |

Packages: `linux-light-lfc` 6.19.5-r3, `device-light-lfc` 1-r15. After installing, updates come with `sudo apk upgrade`.
